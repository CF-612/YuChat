# 倒挂裙摆物理诊断与修订路线

## 结论与交付边界

本次用户图中的倒挂裙摆“反重力”已在隔离 Unity 工程重现。主因是当前模型所有 SpringBone 链的 gravityPower=0，裙摆和主要发束 stiffness=8、dragForce=0.9，强烈保持初始方向。软件额外添加的 30° 锥形角限会限制大幅摆动，但本次对照表明它不是静态倒挂不下垂的主因。

当前未交付自然度修复。只增加可还原诊断工具，原 VRM、默认物理参数和已打开的 Unity 主工程会话均保留；未打包。统一调软候选已否决，不能把实验成功运行描述成画面通过。

基线：0aeab1c，Unity 6000.4.0f1，UniVRM 0.131.4；当前模型 SHA-256 为 5d5762143b093f71bfd513b69449f36097a7300e414bcc1b84853604b6ea3e2d。复用本地 UniVRM UpdateFastSpringBoneJob、SetJointLevel 与既有 PortableSpringPhysics，不引入新求解器。

## 实测

同一模型、同一尾巴倒挂动作采样姿态，固定 60Hz，分别稳定求解 4 秒。每组重新写入参数，避免上一组污染。正式证据只采用 `evidence/inverted-physics-2026-11-04-r3`；首轮存在组间参数残留，r2 是诊断脚本编译失败，不可作为验收。

| 对照 | 倒挂裙摆结果 | 判断 |
| --- | --- | --- |
| 当前配置：作者参数 + 软件 30° 角限 | 裙摆末端仍在根部上方约 5 cm | 重现用户问题 |
| 作者配置：仅移除软件角限 | 基本相同，仍在上方约 5 cm | 单纯撤掉角限不解决问题 |
| 实验：刚性上限 0.65、重力下限 1.5、阻尼上限 0.65，作者角限不变 | 末端落到根部下方约 5 cm，头发也下垂 | 引擎能响应重力，但裙层塌陷、装饰/尾鳍变形，不可发布 |

这些参数是判别原因的强对照，不是推荐预设。Unity 原生 solver 的重力/刚性单位不能当作牛顿或现实布料参数。当前截图能评价静态形状，不能证明连续摇晃、恢复或落地自然。

模型有 8 个碰撞体、2 个碰撞组：裙摆与尾巴引用组 0，主要头发引用组 1，耳鳍和尾鳍未引用碰撞组。裙摆每条链 3 个关节。当前 solver 对每条链检查其配置碰撞体，不包含裙层网格之间的自碰撞，因此不能靠一个重力倍率保证多层裙摆不穿插。

## 修订顺序

| 优先级 | 修订内容 | 验收与限制 |
| --- | --- | --- |
| P0 | 用角色包显式声明柔软发束、裙摆、保形装饰、尾部的物理材质；运行时只读取通用材质参数，不识别角色 SHA 或猜骨名 | 旧包无配置时仍保留作者值；换模型映射由配置提供，不加 C# 特判 |
| P0 | 发束/裙摆恢复非零世界重力，分别调整刚性、阻尼、弯曲范围；作者明确角限优先 | 正立轮廓保留；侧倾、抓头、尾巴倒挂均可垂落，装饰不塌陷 |
| P0 | 检查裙摆根部固定、身体碰撞体、内外层覆盖和倒挂路径 | 先用已有 UniVRM 碰撞；无法表达的裙层约束明确记为资产/求解能力边界，不伪称全部防穿模 |
| P1 | 复查运动输入：现有反向速度平方外力、上限 0.8、center 平移继承 8% | 同一动作比较 30/60/90Hz、三个尺度；慢移动、急停、摇晃、落地分开检查，不把风力同时当惯性和重力 |
| P1 | 转动惯性与恢复：当前补偿仅处理空间根平移，center 的旋转仍完全沿用作者行为 | 尾巴倒挂不是空间根旋转，不能只读取根 rotation 判姿态；不在每帧重建 SpringBone |
| P1 | 既有抓头/摇晃/下落/抚摸压缩回归 | 记录正常速度连续画面、峰值、回稳时间、结构重建次数；模型切换和暂停后无旧缓存冲量 |
| P2 | 在上述边界确定后，才评估现成布料求解器 | 不因本次零重力配置问题就更换引擎；新增求解器须验证 Quest 性能与现有骨骼/表情兼容 |

## 复现

关闭隔离验证工程后执行；不需要关闭主工程：

```powershell
./tools/run-m1-check.ps1 -EvidenceDirectory evidence/inverted-physics-review -Method LingChatXR.Editor.InvertedPhysicsProbe.Run
```

脚本依赖当前本地测试模型与尾巴候选动作，只写隔离进程内 JointLevel 参数。输出六张正立/倒挂对照图及 comparison.json，`passed` 仅表示诊断运行完成，不是自然度或 Quest 验收。未将模型或画面公开上传；源码与报告按批同步。
