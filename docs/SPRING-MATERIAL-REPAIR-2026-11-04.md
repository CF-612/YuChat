# 分部位物理材质与倒挂裙摆修订

接续 a830fb3 的诊断，Unity 6000.4.0f1 / UniVRM 0.131.4。当前模型的 VRM SHA-256 仍为 5d5762143b093f71bfd513b69449f36097a7300e414bcc1b84853604b6ea3e2d，未改 VRM、网格、贴图或骨骼权重。主工程正在由用户使用，验证均在隔离工程执行。未构建 APK。

## 已落地

角色包新增可选 springPhysics 配置。通用运行时代码按显式链序号与根节点校验绑定，映射到物理材质；不检查角色 SHA，不按骨名关键词自动分类。旧包不提供该配置时保留既有行为。无效材质值拒绝应用，根节点不匹配时告警并保留原参数。未来新模型需维护自己的链映射；不能假定模型换骨架后旧映射仍适用。

材质分别提供根部/末端刚性、重力、阻尼、弯曲范围，沿链渐变；作者明确的角限优先。只通过 UniVRM SetJointLevel 写运行时缓冲，碰撞、积分与约束仍复用原生求解器，未增加并行物理系统。

当前角色包绑定八条裙摆链和五条主要发束。裙摆根部保留支撑、末端允许下垂；发束使用保守幅度，尾部、耳鳍、尾鳍与呆毛仍采用既有配置。数据放在 tools/physics-profiles/smallbluefish-spring-materials.json，映射属于角色资产配置，不写死在 C#。

## 可见结果及限制

24 cm 模型的固定倒挂姿态对照：八条裙链末端相对根部平均高度由 **+47.15 mm** 改为 **-31.62 mm**。截图中裙摆已向世界下方翻落，尾鳍与耳鳍没有使用上批统一调软造成的塌陷参数。正立图保留基本轮廓，但物理改变仍需用户判断自然度。

头发大角度下垂候选已否决：倒挂可见发片硬折，收紧至较大的角度仍不合格。最终只采用低重力、保守角限的发束响应。因此**本批没有解决头发完全倒挂下垂，也不能宣称多层裙摆绝不穿插**。裙层间自碰撞仍不在现有 SpringBone 能力内。真实尾巴扑腾全周期、快速转动、多视角自然度与 Quest 仍待验收。

## 使用与回退

本机当前测试角色包已应用候选，退出并重新进入 Play Mode 后重新载入模型即可。复现安装配置：

```powershell
./tools/prepare-spring-materials.ps1
```

恢复旧默认物理：

```powershell
./tools/prepare-spring-materials.ps1 -RestoreDefaults
```

脚本只修改角色包 manifest 的 springPhysics 字段，原 VRM 不变。克隆源码后须有本地模型资源并运行准备脚本；GitHub 不上传测试 VRM。

后续继续检查倒挂裙摆碰撞覆盖及头发蒙皮的大角度能力，再做完整扑腾动作、连续旋转与正常速度画面的自然度验收。保持本次保守发束作为可回退配置。
