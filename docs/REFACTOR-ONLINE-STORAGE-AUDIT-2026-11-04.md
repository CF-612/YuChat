# R1d 在线只读容量盘点

## 交付

宿主新增需要 Bearer 认证的 `GET /storage-summary`，只返回聚合信息：已提交会话/历史/句段数量、日志字节数、音频引用数量/字节数、缺失与未引用数量。不返回聊天正文、角色名、音频文件名、目录和凭据。该诊断入口不进入 Quest 配对网关白名单。

存储写锁保证已提交记录及游标一致；阻塞文件扫描放在线程池，不持有会话总锁。盘点排队时停止会话仍可执行。音频文件可在扫描期间继续生成，因此明确标记 `audioReferenceScope=committed-history`、`audioFileSizesAreLive=true`、`readOnly=true`。未引用数量不能直接作为删除清单；此次没有清理接口。

原离线 `--audit-session-audio` 仍可用，旧 `sessions.json` 与新日志兼容。在线错误只返回固定说明，详细文件内容不进入响应。

## 验证与复现

1. `cargo test --offline --locked --target-dir tools/xr-host/target/c0 --manifest-path tools/xr-host/Cargo.toml`：44 项通过。覆盖认证、已提交/未提交区分、无正文泄漏、不修改磁盘、停止不被存储等待阻塞、损坏日志明确失败、网关拒绝该路由。
2. `./tools/run-catalog-integration.ps1`：独立真实宿主 13 项 HTTP 检查和 Unity 6 Play Mode 10 项通过。通过真实接口核对 155 条历史/105 个句段的盘点，并复验角色切换、设置保存关闭、历史分页、重连与不重播旧音频。
3. 本地证据：`evidence/catalog-integration-20261104-212153/host-checks.json`、`unity-checks.json` 和 `M1-20261104-212209.log`。

使用独立验证可执行文件与私有测试目录；用户正在运行的服务未停止或覆盖，真实历史未迁移。真实服务暂时仍是旧二进制，不能因代码已推送就声称该实例已有新接口。

## 现有规模只读核验

通过独立验证程序的离线只读入口检查现有数据，只输出聚合值：旧历史文件 29,267 字节；76 个引用音频共 40,500,408 字节；缺失引用与非法引用均为 0；3 个未引用音频共 1,364,172 字节。没有删除、重写或迁移，读取时文件可能仍由原服务使用。这些数值仅为本次观察，不是后续实时统计。

当前规模没有足够依据引入新索引层。现有流式扫描、有限内存缓存和异步磁盘读取已覆盖本轮需求；后续若实际历史规模或测量耗时明显增加再评估。
